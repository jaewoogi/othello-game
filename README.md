# 오델로

Vite + React + JavaScript로 만든 1인용 오델로 게임입니다.

## 실행

```cmd
npm install
npm run dev
```

## 검증

```cmd
npm run lint
npm run test
npm run build
```

## 주요 기능

- 하/중/상 AI
- 동전 던지기로 흑/백 무작위 배정
- 정확한 8×8 오델로 규칙
- 자동 패스와 종료 판정
- 350ms AI 대기 표시
- 키보드 접근 가능한 버튼 UI
- 320px 이상 반응형
- 결과 모달에서 재시작/난이도 변경/나가기
